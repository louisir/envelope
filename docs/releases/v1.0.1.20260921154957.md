# Envelope v1.0.1.20260921154957

## 简体中文

本次发布包含 Windows x64 自包含 portable 与 Android ARM64 APK，两端统一构建号，并内嵌按当前界面与行为复核的简体中文 / 英文对照用户手册。

### Windows portable 替换修复（2026-09-21）

本次在原 release 内替换 Windows portable 和校验文件，保留版本号、tag 与发布时间；Android APK 未变。修复编辑同步入口时后台刷新覆盖未保存文字的问题，同时保留光标、选区及其他未保存设置。保存失败保留草稿，成功后回读规范化地址，保存期间的新编辑不会被覆盖。另修复从设置、关于或头像页返回消息／联系人／开封时，左侧旧选中状态导致点击无效的问题。Windows 核心检查在上一轮通过，本轮最终包的 173 项 WPF UI 检查通过（包括 14 项设置草稿回归和 30 项导航回归），ZIP 全部条目校验通过。

### 更新内容

- Windows 改为常驻系统托盘的即时通信布局，图标与浅色配色对齐 Android，另支持深色主题。关闭窗口隐藏到托盘；右键直接显示小圆角菜单。
- Windows 使用独立六位应用解锁码，不依赖 Windows Hello 或 Windows 账户密码。首次初始化为 `123456`，请在“设置 → 安全”修改；已有自定义码不会因升级重置。
- 修复托盘解锁流程、深色下拉菜单、输入框光标、最大化底部边距、滚动条和编辑工具栏悬停边框；筛选按钮改为图标，统一关于页图标与版本显示。
- 两端接入 HA v2 签名集群发现、可信引导、主节点重新发现、持久化投递重试与双副本存储证明。群消息与控制事件逐收件人保存密文后投递，支持有界坏密文隔离和因果延迟重试。
- 支持 `envelope://yourturn/open` 与 `.envelope` 文件交接。
- 更新双语 README、Android 与 Windows 用户手册。手册明确区分两端的锁屏、语言和主题行为，并说明“可靠保存”“已送达”与“已读”的区别。

### 下载与使用

| 平台 | 文件 | 要求 |
| --- | --- | --- |
| Windows | `Envelope-win-x64-1.0.1.20260921154957.zip` | Windows x64；内含 .NET 8 运行时 |
| Android | `envelope-v1.0.1.20260921154957-release.apk` | ARM64；Android 7.0 / API 24 及以上 |

- Windows 完整解压后运行 `Envelope.Windows.exe`。升级前从托盘退出旧版，再运行新版。免安装不代表数据随 ZIP 移动：私有状态保存在 `%LOCALAPPDATA%\Envelope`，迁移请使用恢复词与本地备份。
- Windows 锁定后，左键托盘图标或右键选择“解锁并打开”，输入应用解锁码。Android 使用系统 PIN、密码或生物识别，不使用 Windows 的默认解锁码。
- Android 包名 `com.iamlouis.envelope`，versionName `1.0.1`，versionCode `22751417`，目标 API 36；使用原 Release 证书签名，未启用 ADB bridge。同包名、同签名可覆盖升级；旧包 `com.westwardsoft.envelope` 的数据不会自动迁移。
- 两份手册均随包提供，可从“关于”打开。一个身份当前只支持一个活跃消息终端，恢复到另一平台是显式迁移，不是多端同步。

## English

This release includes the Windows x64 self-contained portable package and Android ARM64 APK with the same build identifier. Both packages bundle Simplified Chinese / English user manuals reviewed against the current UI and behavior.

### Windows portable replacement (2026-09-21)

The Windows portable and checksum assets are replaced within this existing release; the version, tag and publication time are retained, and the Android APK is unchanged. Background refresh no longer overwrites an unfinished relay address, caret, selection or other unsaved settings. Failed saves retain the draft; successful saves read back the normalized address without overwriting edits made during saving. Also fixes inactive sidebar clicks when returning from Settings, About or the profile button to the previously selected Messages, Contacts or Unseal page. Windows core checks passed in the preceding fix; all 173 WPF UI checks passed against this final package (including 14 settings-draft and 30 navigation regressions), and every ZIP entry passed integrity verification.

### Changes

- Windows now uses a tray-based messenger layout, with Android-aligned icons and light colors plus a dark theme. Closing the window hides it to the tray; right-click opens a compact rounded menu directly.
- Windows uses an independent six-digit app unlock code, without Windows Hello or Windows account authentication. The initial code is `123456`; change it in Settings → Security. Upgrading preserves an existing custom code.
- Fixes cover tray unlocking, dark dropdowns, caret alignment, maximized bottom spacing, scrollbars, and clipped composer hover borders. Filters use icons; About artwork and version display are consistent.
- Both clients integrate HA v2 signed cluster discovery, pinned bootstrap trust, leader rediscovery, durable delivery retries, and dual-replica storage proofs. Group messages and control events retain per-recipient ciphertext before delivery, with bounded poison quarantine and causal deferral.
- Supports `envelope://yourturn/open` and `.envelope` file handoff.
- Updated bilingual README and Android / Windows manuals. The manuals distinguish platform-specific locking, language, and theme behavior, and explain reliable storage, delivery, and reading as separate states.

### Download and Use

| Platform | File | Requirements |
| --- | --- | --- |
| Windows | `Envelope-win-x64-1.0.1.20260921154957.zip` | Windows x64; .NET 8 runtime included |
| Android | `envelope-v1.0.1.20260921154957-release.apk` | ARM64; Android 7.0 / API 24 or later |

- Extract the entire Windows ZIP and run `Envelope.Windows.exe`. Quit the old app from its tray menu before upgrading. Installation-free does not mean private data travels with the ZIP: state remains in `%LOCALAPPDATA%\Envelope`; use the recovery phrase and local backup to migrate.
- After locking Windows, left-click the tray icon or choose Unlock and open, then enter the app code. Android uses system PIN, password, or biometrics, not the Windows default app code.
- Android package ID: `com.iamlouis.envelope`; versionName: `1.0.1`; versionCode: `22751417`; target API: 36. The APK retains the Release signing certificate and does not enable the ADB bridge. The same package ID and signature support in-place updates; data from `com.westwardsoft.envelope` is not migrated automatically.
- Both manuals are bundled and accessible from About. An identity currently has one active messaging endpoint; restoring on another platform is an explicit migration, not multi-device synchronization.

### Verification and Limitations

- Rust workspace: 82 tests passed; 14 environment-dependent integration tests skipped by default.
- Flutter analyze reported no issues; 89 Flutter tests and one separately executed native signature-vector test passed.
- Windows core verification, 129 WPF UI checks, and shared client contract checks passed.
- Both manuals were checked at desktop and phone widths with working contents links; the bundled ZIP/APK manuals match their source files byte for byte.
- APK signature, 16 KiB alignment, archive integrity, and SHA-256 checks passed.

These are local engineering and packaging checks. This release did not rerun phone installation, real-device cross-platform messaging, or production failure exercises. Full HA partition, capacity, and endurance acceptance remain open; the project remains an MVP without an independent security audit. Previous engineering and public-server process-failure evidence is in the [HA verification record](https://github.com/louisir/envelope/blob/v1.0.1.20260921154957/docs/ha-v1.0.1-verification.md). The original Android build source is `bceafe50d311c18cd25f67cec0202bd72f8e45ef`; the replacement Windows package is built from `ac1c52ad94fbf05b2e14edeaa3b2d95f564bf765`. The original release tag remains unchanged; the Windows fix is on master.
