单活跃终端：一个身份当前只能选择一个活跃消息终端。恢复到另一台电脑或 Android 手机是显式迁移，不是多端同步。One active endpoint: an identity currently has one active messaging endpoint. Restoring it on another PC or Android phone is an explicit migration, not multi-device synchronization.

1. 安装、托盘与导航 / Install, Tray, and Navigation

从 GitHub Release 下载 Windows x64 portable ZIP，完整解压后运行 Envelope.Windows.exe。本次发布包自带 .NET 8 运行时，无需另外安装。升级时先从托盘退出旧版，再将新版解压到新目录运行，保留旧包以便回滚。Download the Windows x64 portable ZIP from GitHub Releases, extract the entire archive, and run Envelope.Windows.exe. This release includes the .NET 8 runtime. To upgrade, quit the old app from its tray menu, extract the new package to a new folder, and keep the old package for rollback.

免安装不代表私有数据保存在解压目录。身份和聊天状态位于 %LOCALAPPDATA%\Envelope，由当前 Windows 用户保护；复制 ZIP 到另一台电脑不会迁移身份。Installation-free does not mean private data lives beside the executable. Identity and chat state are stored under %LOCALAPPDATA%\Envelope and protected for the current Windows user. Copying the ZIP to another PC does not migrate identity.

默认进入“消息”。左栏提供消息、联系人和信封；头像或齿轮打开设置，问号打开关于。会话筛选图标依次代表“全部 / 未读 / 群聊”；联系人筛选图标依次代表“全部 / 联系人 / 群聊”。将鼠标停在图标上可查看提示。The app opens on Chats. The left rail provides Chats, Contacts, and Open; the avatar or gear opens Settings, and the question mark opens About. Conversation filters are All / Unread / Groups; contact filters are All / Contacts / Groups. Hover over an icon to see its tooltip.

关闭窗口会隐藏到系统托盘，后台同步继续。左键单击托盘图标打开窗口；右键直接显示小圆角菜单，选择“打开主窗口”恢复窗口，选择“退出 Envelope”结束程序。勿扰只暂停通知，仍保留未读状态。Closing the window hides it to the system tray while background sync continues. Left-click the tray icon to open the window; right-click opens its rounded menu directly. Choose Open Envelope to restore the window or Quit Envelope to exit. Do not disturb suppresses notifications while preserving unread state.

新消息通知默认只显示未读数量，弹出受 Windows 通知设置控制。只有当前聊天页面可见且窗口处于活动状态时才会标记已读；隐藏到托盘不会自动清除未读。New-message notifications show unread counts by default and are subject to Windows notification settings. Messages are marked read only when the current chat is visible and the window is active; hiding to the tray does not clear unread state.

2. 身份与联系人 / Identity and Contacts

创建或恢复身份 / Create or Restore Identity

在“设置 → 我的身份”填写显示名，点击“创建身份”。离线抄写生成的 BIP39 24 词恢复词并核对顺序；恢复词窗口会在 2 分钟后关闭，不要通过聊天、邮件或截图保存恢复词。In Settings → My identity, enter a display name and choose Create identity. Write down the generated BIP39 24-word recovery phrase offline and check its order. The phrase window closes after two minutes; do not save the phrase in chats, email, or screenshots.

仅恢复身份：输入原来的 24 词，选择“从恢复词恢复身份”并确认替换。恢复联系人和群组：使用“本地备份 → 用恢复词和本地备份恢复”。同一恢复词对应同一 Key ID，但不会单独恢复聊天记录或文件。To restore identity only, enter the original 24 words, choose Recover identity from phrase, and confirm replacement. To restore contacts and groups, use Local backup → Restore from phrase and local backup. The same phrase restores the same Key ID, but does not by itself restore chat history or files.

添加与验证联系人 / Add and Verify Contacts

在联系人页出示二维码，让 Android 扫描；Windows 可以读取保存的二维码图片，也可粘贴签名 Contact / IntroBundle 文本。同步服务可用时，二维码短期会话支持双向互加，双方仍需分别确认。Show your QR code on the Contacts page for Android to scan. Windows can read a saved QR image or accept signed Contact / IntroBundle text. With a working sync service, the short-lived QR session supports mutual contact exchange; each side still confirms independently.

保存前通过另一条可信通道核对身份指纹（fingerprint）。有效签名证明数据未被篡改，不能自动证明现实身份。联系人可设置备注或删除；删除时会尝试发送加密删除通知，但不能保证对方立即在线处理。Before saving, compare the fingerprint through another trusted channel. A valid signature proves integrity, not real-world identity. You can set a contact note or delete the contact. Deletion attempts to send an encrypted notice, but cannot guarantee immediate processing by the peer.

3. 消息与文件 / Messages and Files

选择会话后输入文本，Enter 发送，Shift+Enter 换行。切换会话会保留本次运行中的草稿。附件图标用于发送在线文件；“发送离线信封”用于生成外部转交的密文文件。Select a conversation and type a message. Enter sends; Shift+Enter inserts a line break. Drafts are retained across conversation changes during the current run. Use the attachment icon for online files and Send offline envelope to create a ciphertext file for external transfer.

会话先加载最近 100 条消息，“加载更早消息”继续向前分页。支持 Ctrl / Shift 多选后“删除所选”，也可点击单条消息的删除图标。这些操作只删除本机记录。A conversation initially loads its latest 100 messages; Load earlier messages retrieves more. Use Ctrl / Shift to select several messages and Delete selected, or use an individual message’s delete icon. These actions affect local records only.

投递状态 / Delivery States

“可靠保存”与“已送达”含义不同：前者证明中继持有符合协议要求的副本，后者要求接收方签名结果；均不表示对方已经阅读。群组按每位收件人独立投递。Reliable storage and delivery are different: storage proves the relay holds the protocol-required replicas, while delivery requires a signed recipient result. Neither means the person has read the message. Groups deliver independently to each recipient.

界面状态 / UI state含义 / Meaning
暂存，等待可靠保存Staged, awaiting durable storage尚未取得可靠保存证明，本机保留重试副本。No reliable-storage proof yet; a retry copy remains locally.
已可靠保存，等待接收Reliably stored, awaiting recipient已取得双副本保存证明，仍待接收方处理。Dual-replica storage is proved; recipient processing is still pending.
已送达Delivered已验证接收方签名的送达结果。A recipient-signed delivery result has been verified.
等待接收方处理Awaiting recipient processing接收方暂缓处理，例如等待前置群事件。Recipient processing is deferred, for example pending an earlier group event.
接收方已拒绝Rejected by recipient接收方返回拒绝结果。The recipient returned a rejection.
保存期限已过Retention expired本次信封有效期结束，不应继续等待其送达；不代表所有磁盘副本已物理删除。The envelope lifetime ended; do not keep waiting for delivery. This does not prove physical deletion of every disk copy.

文件 / Files

在线单文件上限 64 MiB，按 4 MiB 分片加密，并校验分片与整文件 SHA-256。接收完成的文件保存到 %USERPROFILE%\Downloads\Envelope\received；通过聊天中的文件入口交给系统默认应用打开。The online file limit is 64 MiB, encrypted in 4 MiB chunks with chunk and whole-file SHA-256 checks. Completed files are saved under %USERPROFILE%\Downloads\Envelope\received. Open them from the chat file action using the system default application.

4. 群组 / Groups

创建群组至少选择两位联系人，加上群主共三人。普通群在接受邀请后成为活跃成员；验证群只向本机已核对并信任指纹的活跃成员发送；共识群接受后还需要达到 60% 活跃成员背书阈值。Select at least two contacts to create a group of three including the owner. Normal-group invitees become active after accepting. Verified groups send only to active members whose fingerprints are trusted locally. Consensus groups also require the 60% active-member endorsement threshold after acceptance.

在群组管理中查看成员和指纹，通过可信通道核对后再信任或背书。本机指纹信任不会作为远端控制事件替你自动建立。群主可邀请或移除成员、改名及更新头像 seed；群主退出或有效成员少于三人时会停用群组并发送带原因的控制事件。Inspect members and fingerprints in group management, verify them through a trusted channel, then trust or endorse them. Remote control events do not automatically establish local fingerprint trust. Owners can invite or remove members, rename the group, and update its avatar seed. Owner departure or fewer than three effective members deactivates the group with a reason-bearing control event.

群文本、文件与成员控制事件逐收件人独立加密，不使用共享群密钥。发送前会持久化待投递密文，中断后使用原 envelope ID 重试未完成项。Group text, files, and membership-control events are encrypted separately for each recipient without a shared group key. Pending ciphertext is persisted before delivery and unfinished items retry with the original envelope ID after interruptions.

5. 密封与拆封 / Seal and Open

在联系人或有效群会话中选择“发送离线信封”，选择文本或本地文件，生成 .envelope 后通过邮件、网盘或 U 盘交付。输出位于 %USERPROFILE%\Downloads\Envelope\sealed。离线文件不受在线 64 MiB 限制，但仍受可用磁盘空间限制。In a contact or active group conversation, choose Send offline envelope and select text or a local file. Transfer the resulting .envelope by email, cloud storage, or USB. Output is under %USERPROFILE%\Downloads\Envelope\sealed. Offline files are not subject to the online 64 MiB limit, but require sufficient disk space.

接收方从“信封 / Open”页面选择文件并“解密并导入”；单体信封也可粘贴 base64。群组流会跳过写给其他成员的密文，并校验当前成员关系、签名和重放计数。校验成功后才写入聊天记录或接收文件。The recipient selects the file on the Envelope / Open page and chooses Decrypt and import. A single envelope can also be pasted as base64. Group streams skip ciphertext for other members and verify current membership, signatures, and replay counters before saving chat records or received files.

Windows 注册当前用户的 .envelope 文件关联。双击文件可交给程序导入；envelope://yourturn/open 激活已有程序并进入拆封页。尚未建立身份时，文件请求会等到创建或恢复身份后继续处理。Windows registers a per-user .envelope file association. Double-click a file to import it. envelope://yourturn/open activates the existing app and opens the Open page. If no identity exists, file processing waits until identity creation or recovery.

一对一流使用 ENVELOPE_STREAM_V1，群组流使用 Android 兼容的 ENVELOPE_GROUP_STREAM_V1；群组密文体积随收件人数增长。外部渠道只负责传输密文，不承担解密。One-to-one streams use ENVELOPE_STREAM_V1; group streams use Android-compatible ENVELOPE_GROUP_STREAM_V1. Group ciphertext grows with recipient count. External channels transport ciphertext and do not decrypt it.

6. 消息同步 / Message Sync

本次发布包含 HA 中继引导配置和可信管理员公钥。程序校验签名集群信息并重新发现可用主节点；无需把备用节点逐一手动设为入口。自建部署需要匹配的信任配置，单独修改地址不能绕过校验。This release includes HA relay bootstrap configuration and a trusted administrator public key. The client verifies signed cluster information and rediscovers the available leader; you do not need to select each standby manually. Self-hosted deployments need matching trust configuration; changing an address alone cannot bypass verification.

在“设置 → 消息同步”启用“自动同步”。需要修改入口时，在“中继矩阵入口”填写受信任服务的域名或 IP，点击“保存同步入口”，再点击“立即同步”。应用运行且后台同步启用时，隐藏到托盘仍可同步；退出程序后停止。Enable Auto sync in Settings → Message sync. When changing an entry, enter the trusted service domain or IP in Relay matrix entry, choose Save sync entry, then Sync now. With background sync enabled, the running app continues syncing while hidden to the tray; quitting stops it.

直连路径可用时优先使用 P2P；否则通过中继投递。同步会更新接收路由、拉取信封、验证并保存消息，以及处理重试和签名结果。暂存成功不等于可靠保存，可靠保存也不等于已送达，请结合消息状态判断。P2P is preferred when a direct path is available; otherwise delivery uses the relay. Sync updates receive routes, pulls envelopes, verifies and stores messages, and processes retries and signed results. Staging is not reliable storage, and reliable storage is not delivery; check the message state.

同步异常时先核对网络、入口和系统时间，再重试。没有服务器时，已有可用直连路径和离线密封仍可能使用，但依赖中继的投递和二维码互加回传不能保证运行。HA 完整网络分区、容量与长期运行验收仍在进行。For sync errors, check connectivity, entry, and system time before retrying. Without a server, existing usable direct paths and offline sealing may still work, but relay-dependent delivery and QR return exchange are unavailable or unreliable. Full HA partition, capacity, and endurance acceptance is still in progress.

7. 备份与迁移 / Backup and Migration

“设置 → 本地备份 → 导出本地备份”用当前身份自加密，不要求再次输入恢复词。备份包含显示名、Key ID、联系人、群组、群成员、相关群事件与重放状态、同步入口及自动备份策略。Settings → Local backup → Export local backup encrypts a backup to the current identity without asking for the phrase again. It contains display name, Key ID, contacts, groups, members, associated group events and replay state, sync entry, and auto-backup policy.

备份不含恢复词、裸私钥、聊天记录、received / sealed 文件，以及本机解锁码。启用自动备份后，应用运行或恢复时按计划写入 %USERPROFILE%\Downloads\Envelope\backups，按保留数量清理旧备份。Backups exclude the recovery phrase, raw private keys, chat history, received / sealed files, and the local unlock code. Auto backup checks its schedule while the app runs or resumes, writes to %USERPROFILE%\Downloads\Envelope\backups, and prunes older backups according to retention settings.

迁移时先导出旧端备份并确认持有恢复词，停止旧端收发；在新端填写 24 词并选择“用恢复词和本地备份恢复”。核对 Key ID、联系人及群组，再测试收发。确认新端正常前保留旧端数据，之后不要让两端同时作为活跃消息终端。Before migration, export the old endpoint’s backup and confirm you have the phrase, then stop messaging on that endpoint. On the new endpoint, enter all 24 words and choose Restore from phrase and local backup. Check the Key ID, contacts, and groups, then test messaging. Preserve old data until the new endpoint works, and do not run both as active messaging endpoints.

8. 解锁、安全与存储 / Unlock, Security, and Storage

锁定与解锁 / Lock and Unlock

托盘菜单选择“锁定”后，窗口隐藏且锁定状态跨重启保留。左键单击托盘图标，或右键选择锁定时显示的“解锁并打开”，输入应用的六位数字解锁码即可打开。取消或输入错误不会解锁。Choose Lock from the tray menu to hide the window and persist the lock across restarts. Left-click the tray icon, or right-click and choose Unlock and open (shown while locked), then enter the six-digit app code. Canceling or entering an incorrect code leaves the app locked.

首次初始化解锁码为 123456。请在“设置 → 安全 → 修改解锁码”中输入当前码，并两次输入新码。修改后默认码不再有效，程序升级不会重置自定义码；连续输错五次需等待 30 秒，重启不会清除等待时间。The initial code is 123456. In Settings → Security → Change unlock code, enter the current code and the new code twice. After changing it, the default no longer works, and upgrading does not reset your code. Five incorrect attempts trigger a 30-second wait that persists across restarts.

此码与 Windows Hello、Windows 系统 PIN、Windows 账户密码、Android 锁屏密码及 24 词恢复词不同。请妥善记住；当前界面没有“忘记解锁码”重置入口，恢复词不能代替解锁码。不要删除本机数据文件来尝试解锁。This code is separate from Windows Hello, the Windows PIN or account password, Android screen-lock credentials, and the 24-word recovery phrase. Keep it safe: there is currently no Forgot code reset action, and the recovery phrase cannot replace it. Do not delete local state files to attempt an unlock.

启用“打开 App 时验证身份”后，启动、整个应用离开前台超过 30 秒后返回，以及敏感操作会要求解锁。手动锁定不依赖此开关。离开应用时，显示敏感内容的相关子窗口会关闭。With Require unlock when opening the app enabled, startup, returning after the whole app has been inactive for over 30 seconds, and sensitive actions require unlocking. Manual locking works independently of this switch. Relevant windows showing sensitive content close when leaving the app.

存储与清理 / Storage and Cleanup

本机随机主密钥由 Windows DPAPI CurrentUser 保护，状态槽分别使用 AES-256-GCM 加密。恢复词默认不持久化；解锁码验证记录仅在本机保存，不随备份迁移。Windows DPAPI CurrentUser protects a random local master key, and each state slot uses AES-256-GCM. The recovery phrase is not persisted by default. Unlock-code verification data stays local and does not migrate with backups.

用户文件位于 %USERPROFILE%\Downloads\Envelope 下的 received、sealed、backups 和 diagnostics 目录。“清空文件缓存”会移除 received / sealed 文件，保留聊天条目但不能再打开已删文件。清除本机身份属于破坏性操作，应先备份并确认恢复资料。User files live in the received, sealed, backups, and diagnostics folders under %USERPROFILE%\Downloads\Envelope. Clear file cache removes received / sealed files while retaining chat entries; deleted files can no longer be opened. Clearing local identity is destructive: prepare backups and recovery material first.

9. 语言、主题与帮助 / Language, Theme, and Help

在“设置 → 外观与语言”切换“简体中文 / English”，主题可选“跟随系统 / 浅色 / 深色”。图标的功能名称可通过鼠标悬停提示查看。此手册同时列出两种语言，无需联网或脚本即可阅读。Use Settings → Appearance and language to select 简体中文 / English and Use system setting / Light / Dark theme. Hover tooltips identify icon actions. Both manual languages are available together without a network connection or scripts.

问号进入关于页，可查看版本、时间戳构建号、用户手册、仓库与许可证。发布包包含本 HTML 手册；程序会调用系统默认浏览器打开。与 GitHub Release 附件中的 SHA-256 比较，可核对下载文件。The question mark opens About, with version, timestamp build, user manual, repository, and license information. The package includes this HTML manual, opened through the system default browser. Compare the downloaded archive against the SHA-256 provided in GitHub Release assets.

诊断日志可在设置页导出或清空，记录状态、耗时、错误和网络路径，不记录消息正文、文件内容、私钥或恢复词。报告问题时提供版本号、操作步骤和必要的错误摘要，不要提供解锁码或恢复词。Export or clear diagnostic logs in Settings. They record status, timing, errors, and network paths, not message bodies, file content, private keys, or recovery phrases. When reporting a problem, include the version, steps, and necessary error summary, not your unlock code or recovery phrase.

项目仍为 MVP，尚未经过独立安全审计；HA 工程测试通过不等于完整真实设备与生产验收完成。The project remains an MVP without an independent security audit. Passing HA engineering tests does not mean complete real-device or production acceptance.
